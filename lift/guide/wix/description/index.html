תיאור לגוגל

התיאור לגוגל הוא שתי השורות שמופיעות מתחת לשם האתר בתוצאות החיפוש. בלעדיו, גוגל בוחר משפט אקראי מהדף.

  1. באותו חלון של דף הבית, עוברים ללשונית Basics.
  2. בערכה לוחצים העתקה ליד "טקסט 3: תיאור לגוגל", ומדביקים ב-Meta description.
  3. בודקים ש-Let search engines index this page מסומן.
  4. לוחצים Publish.
